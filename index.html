一个简单、离线、面向开发者的 API 密钥保险箱。默认不上传、不注册、不追踪。

忘记主密码了？这两个按钮别点错

  • 恢复 Vault：用创建时保存的恢复身份文件打开原来的数据，条目一个不少。
  • 重建 Vault：创建空的新 Vault。原文件保留成 vault.age.before-rebuild-…，旧主密码仍能打开它，但当前这个 Vault 是空的。

没有恢复身份文件，就只剩重建这一条路——主密码本身没有任何找回途径。

第一次使用？先说清楚这三件事

  • 你的 Vault 是一份 加密文件——别人拿到也打不开，只有知道主密码的人才能读取。
  • 主密码 无法找回。创建后会给你一份恢复身份，请离线保存。
  • 先「创建 Vault」：定好文件保存位置和主密码，再把项目密钥一条条加进去。

RECOVERY SETUP

保存恢复密钥

这是一把独立的恢复密钥。请保存到 Vault 之外的安全位置；丢失它就无法恢复原数据。

应用同时生成了 Vault.identity.age 恢复身份副本，请和恢复身份文件一起妥善备份。

RECOVERY ACCESS

用恢复身份打开 Vault

  1. 选回原来那个 Vault 文件——下面已经填好默认路径。
  2. 选出创建时保存的恢复身份文件（内容是一行 AGE-SECRET-KEY-1…）。
  3. 设一个新的主密码，以后用它解锁。

恢复完成

  • 原来的条目都在，Vault 已用新主密码重新加密保存。
  • 恢复身份文件依然有效——以后忘了新密码还能用它，请继续妥善保存。
  • 建议现在重新「导出加密备份」一次，和 Vault.identity.age 放在一起。
